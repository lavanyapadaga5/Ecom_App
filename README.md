🛍️ E-Commerce Backend – Django REST API

This project is a simple e-commerce backend where users can browse products, manage cart, place orders, add address, and maintain a wishlist. The system is built using Django REST Framework.

✅ Main Features
1. User Module

User Registration

Login with JWT Token

Logout

User Profile

Update Profile

Change Password

Add Address

2. Product Module

List all products

View a single product

Wishlist (Add / Remove / View favourite products)

3. Cart Module

Add items to cart (single product or bulk add)

View cart

Update quantity

Remove item from cart

4. Order Module

Place an order

View order history

Cancel an order

🔄 Project Flow (Step by Step)

1️⃣ User registers and creates an account
2️⃣ User logs in and gets a JWT token
3️⃣ User views available products
4️⃣ User adds a product to cart
5️⃣ User updates cart quantity or deletes items
6️⃣ User adds delivery address
7️⃣ User places an order

Order is created

OrderItems are created

Cart becomes empty
8️⃣ User checks order history
9️⃣ User cancels an order (if not delivered)
🔟 User saves favourite products in wishlist
